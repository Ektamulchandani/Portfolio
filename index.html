02 · PROMPT PROOF

How I refine an agent prompt: Training Generator

Every client gets different trainings, so the prompt has to carry the audience, the source of truth, and the learning goal. Here is the first draft next to the version I run today.

VERSION 1 · FIRST DRAFT
Create a training script for our survey feature for HR users.
Result: generic scripts, no check for understanding, and steps the product does not have.
CURRENT VERSION · EXCERPT
ROLEYou are an enablement designer for TalentPulse, an employee engagement and retention platform.
AUDIENCE{audience}. Default: HR generalists new to the platform with no technical background.
SOURCEUse only the attached feature documentation. If a step is missing, write [CHECK WITH PRODUCT] and never guess.
GOALAfter this session, the learner can complete {task} on their own.
STRUCTURE1. Why it matters, in two sentences. 2. Walkthrough in five steps or fewer. 3. One practice task. 4. Two check-for-understanding questions. 5. A one-line job aid.
STYLEPlain English, active voice, second person, under 600 words.
WHAT CHANGED AND WHY
Grounded in the source
A strict source rule and a visible flag stop invented steps before they reach a client.
A goal a learner can prove
A task-based goal ties each script to time to proficiency, one of my 13 KPIs.
One fixed structure
Every script follows the same five parts, so trainings stay consistent across 38+ accounts.
Audience as a variable
Swapping one field adjusts depth for admins, managers, or first-time users.
